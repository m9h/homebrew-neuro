# Mhough Neuro

## How do I install these formulae?

`brew install mhough/neuro/<formula>`

Or `brew tap mhough/neuro` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "mhough/neuro"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
